VS Code 1.121: 즐겨찾기 모델 고정, 터미널 출력 압축, 에이전트 SSH

VS Code 1.121은 모델 즐겨찾기, 테스트 러너 및 빌드 도구를 위한 확장 터미널 출력 압축, 백그라운드 터미널의 유휴 무음 타이머, 에이전트 호스트의 키보드 인터랙티브 SSH 인증을 추가합니다.

VS Code 1.121은 1.120의 Copilot 에이전트 품질 개선을 계속하며 모델 관리와 터미널 동작에 초점을 맞춥니다.

즐겨찾기 모델 고정

모델 선택기가 이제 고정을 지원합니다. 항상 같은 모델을 사용한다면 목록 상단에 고정하세요. 여러 제공업체의 많은 모델에 액세스할 때 스크롤을 줄입니다.

확장 터미널 출력 압축

에이전트 터미널 도구는 이미 일반적인 명령의 출력을 압축했습니다. 1.121은 테스트 러너와 빌드 도구를 포함하도록 이를 확장합니다:

  • 테스트 러너: pytest, jest, cargo test
  • 빌드 도구: tsc, cargo build, make
  • 린터, Docker, 패키지 매니저

긴 빌드 출력과 테스트 실패 보고서는 모델에 전달되기 전에 관련 발췌로 압축됩니다. 이를 통해 에이전트가 수천 줄의 출력을 생성할 수 있는 빌드 사이클이나 테스트 스위트를 실행할 때 컨텍스트 사용을 관리 가능하게 유지합니다.

백그라운드 터미널의 유휴 무음 타이머

run_in_terminal 도구의 새 유휴 무음 타이머: 동기 명령이 설정 가능한 기간 동안 출력을 생성하지 않으면 자동으로 백그라운드 실행으로 승격됩니다. 이를 통해 장기 실행 명령이 자동으로 처리할 때 에이전트를 차단하는 것을 방지합니다. 나중에 확인할 터미널 ID를 얻습니다.

VSCODE_AGENT 환경 변수

Copilot Chat이 터미널에서 명령을 실행하면 이제 VSCODE_AGENT 환경 변수가 설정됩니다. 에이전트 세션에서 호출될 때와 대화형으로 호출될 때 다르게 동작하는 스크립트나 도구가 있는 경우 유용합니다.

브라우저에서 채팅에 추가

통합 브라우저를 오른쪽 클릭하면 이제 “채팅에 추가” 옵션이 표시됩니다. 웹 페이지에서 콘텐츠를 선택하고 복사 붙여넣기 없이 Copilot Chat 컨텍스트에 직접 추가합니다.

수정: Agent Host의 다중 행 셸 명령

기다렸던 버그 수정: Agent Host 터미널 도구의 다중 행 셸 명령이 이제 올바르게 작동합니다. 이전에는 실패하거나 잘못된 동작을 일으킬 수 있었습니다.

키보드 인터랙티브 SSH 인증

Agent Host SSH 연결이 이제 키보드 인터랙티브 인증을 지원합니다 — 일부 SSH 서버(일부 구형 기업 구성 포함)에서 사용하는 폴백 인증 방법. 원격 SSH 호스트에서 작업하는 에이전트는 인증 실패를 경험할 가능성이 낮아집니다.
