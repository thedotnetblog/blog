VS Code 1.120: 암호 프롬프트, 컨텍스트 크기 선택기, Agent Host의 GitHub 메타데이터

VS Code 1.120은 Copilot 사용자를 위한 집중 릴리스: 안전한 암호 프롬프트 처리, 모델 컨텍스트 크기 선택기, 에이전트 세션의 GitHub PR 메타데이터, 세션 아카이브 관리.

VS Code 1.120은 개별적으로는 작지만 일상 사용에서 눈에 띄게 개선된 Copilot 에이전트 개선 세트와 함께 출시되었습니다.

에이전트 터미널에서의 안전한 암호 프롬프트 감지

Copilot 에이전트가 암호 또는 패스프레이즈 프롬프트를 발생시키는 터미널 명령을 실행하면, VS Code가 이를 감지하고 확인 대화상자를 표시합니다. 대화상자는 터미널에 포커스를 맞춰 비밀을 직접 입력할 수 있게 합니다 — 중요한 것은 비밀이 모델을 통해 라우팅되지 않는다는 점입니다.

이것은 중요한 보안 개선입니다. 이전에는 인증 프롬프트를 유발하는 명령을 실행하는 에이전트가 사용자가 실수로 자격 증명을 노출할 수 있는 상황을 만들 수 있었습니다. 스크린 리더 알림은 접근성 사용자도 알림을 받는다는 것을 의미합니다.

모델 선택기의 컨텍스트 크기 선택기

새 컨텍스트 크기 선택기를 통해 모델이 세션에 사용하는 컨텍스트 양을 선택할 수 있습니다. 모델마다 컨텍스트 창 크기가 다르며, 일부 워크플로는 이를 제한하거나(낮은 지연, 낮은 비용) 최대화하는(복잡한 코드베이스, 장기 실행 세션) 것의 이점을 얻습니다.

Agent Host 세션의 GitHub PR 메타데이터

GitHub 리포지토리가 지원하는 세션에 대해 VS Code는 이제 GitHub 메타데이터 — 풀 리퀘스트 버튼 포함 — 를 에이전트 호스트 UI에 표시합니다. PR 작업 시 브라우저나 GitHub 확장으로의 컨텍스트 전환이 줄어듭니다.

채팅 세션 아카이브 관리

세션 Quick Pick의 두 가지 개선 사항:

  • 아카이브된 세션은 기본적으로 숨겨짐 (시각적 혼란 감소)
  • 검색은 여전히 아카이브된 세션과 일치하므로 제목으로 복원할 수 있습니다

세션은 또한 기본적으로 최근 순으로 그룹화되어 최근 작업을 더 쉽게 찾을 수 있습니다.

Copilot CLI 플러그인 자동 검색

VS Code는 이제 ~/.copilot/installed-plugins/에서 설치된 Copilot CLI 사용자 플러그인을 자동으로 검색합니다. WinUI 또는 다른 도메인별 에이전트 스킬을 설정한 경우 수동 구성 없이 인식됩니다.

사용자 정의 Diff 편집기 API (미리 보기)

확장 작성자를 위해: 새로운 제안 API customDiffEditorProvider를 사용하면 확장이 두 개의 나란한 사용자 정의 편집기 보기 대신 원본과 수정된 문서 모두에 액세스하여 통합 diff를 단일 webview에서 렌더링할 수 있습니다.
