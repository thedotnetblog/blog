Cosmos DB Shell이 공개 미리 보기 중 — 그리고 MCP 서버가 내장되어 있습니다

Azure Cosmos DB Shell은 데이터베이스 명령을 MCP 도구로 노출하는 새로운 오픈 소스 CLI입니다. AI 에이전트가 당신이 사용하는 것과 동일한 인터페이스를 사용하여 컨테이너를 탐색하고, 쿼리를 실행하고, 데이터를 관리할 수 있습니다.

Cosmos DB 질문 하나에 답하기 위해 포털 탭, SDK 샘플, 반쯤 완성된 스크립트 사이를 왔다갔다 해야 했던 경험이 있다면, 이 프로젝트가 제거하려는 마찰을 이미 알고 있을 것입니다.

Azure Cosmos DB Shell이 방금 공개 미리 보기에 들어갔습니다. bash와 유사한 구문을 가진 오픈 소스 CLI이며 — 이것을 흥미롭게 만드는 부분 — 통합된 MCP 서버를 갖추고 있습니다.

다른 데이터베이스 CLI와의 차별점

CLI 자체는 유용합니다: 친숙한 명령, 스크립팅 지원, CI/CD 통합. 이 부분은 개발자 중심 데이터베이스 도구의 기본입니다.

흥미로운 부분은 MCP 서버 통합입니다. CLI가 노출하는 모든 명령이 AI 에이전트가 호출할 수 있는 MCP 도구로 사용 가능해집니다. 사용자 정의 API 레이어가 없고, 작성할 통합 코드도 없습니다. 에이전트가 다음을 수행할 수 있습니다:

  • cd, ls, pwd로 데이터베이스 계층 구조 탐색
  • query로 SQL 쿼리를 실행하고 구조화된 결과 받기
  • create item, update, rm으로 항목 생성 및 수정
  • mkdb, mkcon, rmdb, rmcon으로 데이터베이스 및 컨테이너 관리
  • endpoint, pwd로 현재 컨텍스트 확인

핵심 변화: 에이전트가 Cosmos DB API와 대화하는 것이 아니라 — 당신이 사용하는 것과 동일한 셸 인터페이스와 대화합니다. 명령은 결정론적이고, 감사 가능하며, 정확히 무슨 일이 일어나고 있는지 검사할 수 있도록 오픈 소스입니다.

오픈 소스 기반이 중요합니다

이것은 블랙박스 관리형 서비스가 아닙니다. 셸은 오픈 소스이며, 이것이 의미하는 바는:

  • 보안 팀이 구현을 감사할 수 있음
  • 플랫폼 팀이 특정 표준에 맞게 포크하고 확장할 수 있음
  • 개발자들이 모두에게 도움이 되는 개선 사항을 기여할 수 있음

AI 도구를 채택하는 기업 팀에게 “정확히 어떻게 작동하는지 볼 수 있습니까"는 점점 더 선택적인 요구 사항이 아닙니다. 여기서 오픈 소스는 의미 있는 차별화 요소입니다.

더 쉬워지는 세 가지 시나리오

지능적인 데이터 분석 — 에이전트를 셸에 연결하고, 자연어로 질문하고, 구조화된 쿼리 결과를 얻습니다. 에이전트는 쿼리 구성을 처리하고, 셸은 실행을 처리합니다.

자율적인 데이터 관리 — Cosmos DB에서 데이터를 생성, 업데이트 또는 제거해야 하는 워크플로우는 사용자 정의 통합 없이 MCP 도구를 통해 수행할 수 있습니다.

실시간 모니터링 및 알림 — 에이전트가 주기적으로 컨테이너를 쿼리하고, 결과를 비교하며, 적절한 알림 채널을 통해 이상 징후를 표시할 수 있습니다.

MCP 인터페이스는 이러한 시나리오를 MCP를 지원하는 모든 AI 플랫폼과 조합 가능하게 만듭니다 — Microsoft 도구만이 아닙니다.

시작하기

셸은 공개 미리 보기 중입니다. 설치하고, Cosmos DB 연결을 구성하고, MCP 서버를 활성화합니다. 거기서부터 MCP 호환 에이전트 호스트라면 어디서든 도구를 검색하고 사용할 수 있습니다.
