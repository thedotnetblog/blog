إضافة MSSQL في VS Code تتحول بهدوء إلى منصة أكبر بكثير

يضيف أحدث تحديث لإضافة MSSQL التزويد لـ Azure SQL، وتصميم المخططات بمساعدة Copilot، وData API builder، ودفاتر الملاحظات. الجزء المثير هو كم من أعمال قواعد البيانات يمكن أن تبقى الآن داخل VS Code.

تمت ترجمة هذه المقالة تلقائيًا. للاطلاع على النسخة الأصلية، انقر هنا.

لقد كانت إضافة MSSQL لـ VS Code تنمو منذ فترة، لكن هذا التحديث الأخير يجعل الاتجاه أوضح بكثير.

لم تعد مجرد «اتصل وشغّل بعض الاستعلامات».

مع دفع تزويد Azure SQL، ومصمم المخططات بمساعدة Copilot، ودفاتر SQL، وData API builder كلها إلى الأمام في إصدار واحد، أصبحت الإضافة مساحة عمل أشمل بكثير للتطوير المرتكز على قواعد البيانات.

الجذب العملي هنا هو التزويد مباشرة من المحرر

يقول المقال الأصلي إنه يمكنك الآن إنشاء قاعدة بيانات سحابية مُدارة بالكامل «مباشرة من المحرر وبدون تكلفة» باستخدام الطبقة المجانية.

هذا هو نوع الميزة التي تبدو صغيرة حتى تدرك مقدار الاحتكاك الذي تزيله من عملية الإعداد.

بالنسبة لكثير من المطورين، الجزء المزعج في التجارب الثقيلة بالبيانات ليس SQL نفسه. بل الفجوة البيئية بين:

  • الفكرة
  • قاعدة البيانات
  • المخطط
  • API
  • backend قابل للاختبار

إذا قصرت هذه الفجوة داخل أداة واحدة، يصبح سير العمل كله أكثر جاذبية.

هذا ما تبدو عليه حلقة داخلية أقوى لأعمال البيانات

ما يعجبني في هذا الإصدار هو أنه يبقي جزءًا أكبر من سير عمل قاعدة البيانات في مكان واحد:

  • تزويد قاعدة البيانات
  • تصميم المخطط
  • مراجعة التغييرات
  • توليد سكربتات ORM
  • إتاحة واجهات API
  • اختبار نقاط النهاية
  • التوثيق والاستعلام عبر الدفاتر

هذه قصة أكثر إقناعًا بكثير من معاملة SQL كأداة جانبية منفصلة في البنية.

سير عمل المخطط بمساعدة Copilot هو المكان الذي تبدو فيه قيمة الذكاء الاصطناعي حقيقية

إضافات مصمم المخططات مثيرة للاهتمام بشكل خاص لأنها تبدو وكأنها تضرب توازنًا جيدًا.

القيمة ليست «الذكاء الاصطناعي يصمم نموذج البيانات الخاص بك وأنت تثق به بشكل أعمى».

القيمة هي:

  • نقاط بداية أسرع
  • مراجعة مرئية
  • تتبع التغييرات
  • مخرجات موجهة للهجرة
  • ضوابط قبول/تراجع واضحة

هذا سير عمل ذكاء اصطناعي أكثر صحة بكثير من توليد تلقائي كامل بلا مسار فحص.

وفي أعمال قواعد البيانات، قابلية المراجعة مهمة جدًا.

Data API builder مضاعف هادئ

الميزة الأخرى التي لا ينبغي تجاهلها هي تكامل Data API builder.

إذا أمكنك الانتقال من المخطط إلى:

  • REST
  • GraphQL
  • نقاط نهاية MCP

داخل البيئة نفسها، فإن ذلك يخلق مسارًا فعالًا جدًا للنماذج الأولية الخلفية والأدوات الداخلية.

هذا لا يستبدل الهندسة الخلفية الأعمق. لكنه يختصر الطريق من فكرة قاعدة البيانات إلى واجهة عمل فعلية.

وجهة نظري

هذا الإصدار يجعل إضافة MSSQL تبدو أقرب إلى منصة صغيرة داخل VS Code من كونها مجرد ملحق بسيط.

بالنسبة للمطورين الذين يبنون واجهات API، وأدوات بيانات، وأدوات إدارة، أو نماذج أولية مدعومة بـ SQL، فهذا تحول مهم.

وإذا واصلت Microsoft تضييق هذه الحلقة، ستصبح الإضافة أكثر فائدة استراتيجيًا بكثير مما يظنه كثير من الناس.
