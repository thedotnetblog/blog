[VS Code 1.119](https://code.visualstudio.com/updates/v1_119) صدر في 6 مايو 2026 (مع تحديث أمني 1.119.1 بعده بفترة قصيرة). يركز الإصدار على قابلية مراقبة الوكلاء، التفاعل مع المتصفح، وتقليل المقاطعات.

## تتبع OpenTelemetry لجلسات الوكلاء

هذه الميزة البارزة لكل من يشغّل وكلاء في الإنتاج أو يصحح سير عمل الوكلاء. فعّلها بإعدادين:

```json
"github.copilot.chat.otel.enabled": true,
"github.copilot.chat.otel.otlpEndpoint": "http://localhost:4318"
```

تتبع الآثار معايير GenAI الدلالية. كل طلب وكيل ينتج نطاق جذر `invoke_agent` مع نطاقات فرعية متداخلة: `chat` و`execute_tool` و`execute_hook`. يُرفع استخدام الرموز المميزة لكل طلب — بما في ذلك أعداد قراءة ذاكرة التخزين المؤقت وإنشائها.

يعمل مع الوكيل المحلي، وكيل Copilot CLI في الخلفية، ووكيل Claude. أي خلفية متوافقة مع OTLP تقبل الآثار — [لوحة تحكم Aspire المستقلة](https://learn.microsoft.com/en-us/dotnet/aspire/fundamentals/dashboard/standalone) تعمل بشكل جيد للتطوير المحلي.

## الوكلاء يمكنهم الآن الوصول إلى تبويبات المتصفح

يمكن للوكلاء طلب الوصول إلى تبويبات متصفحك المتكاملة — لكنه ليس تلقائياً. يجب عليك مشاركة التبويب صراحةً عبر منتقي السياق، السحب والإفلات، أو السياق المقترح. هناك زر مشاركة في المتصفح لإلغاء الوصول. عندما يحاول وكيل فتح تبويب جديد على نفس النطاق كتبويب مفتوح (غير مشارك)، يطلب VS Code منك إعادة استخدام التبويب الموجود.

## تحسين استخدام الرموز المميزة

نموذج خفيف تجريبي يتولى الآن إدارة قوائم مهام الوكيل، مُبقياً هذه الأعمال الإدارية بعيدة عن النموذج الأساسي الأكثر تكلفة. يقلل استهلاك الرموز المميزة للمهام التي لا تحتاج إلى قدرة استدلال كاملة.

## الثقة والأمان

مقاطعات أقل: VS Code 1.119 يقلل المطالبات لطلبات الوصول إلى الشبكة وكتابة المجلد المؤقت من قبل الوكلاء. تعالج التصحيحية 1.119.1 ثغرات أمنية محددة — يستحق التحديث إذا لم تفعل بعد.

## تبديل سريع لمعاينة Markdown

صغير لكن مفيد: يمكنك الآن التبديل السريع من المحرر الحالي إلى معاينة Markdown دون التنقل بعيداً.

## VS Code Agents (معاينة Insiders)

واجهة جلسة الوكيل المُعاد تصميمها — منتقي مستودعات جديد (محلي/مستودعات/بعيد)، تحسينات الجلسات الفرعية، تحسين الويب والهاتف المحمول، رسوم متحركة للتقدم — متاحة في Insiders على [insiders.vscode.dev/agents](https://insiders.vscode.dev/agents).
