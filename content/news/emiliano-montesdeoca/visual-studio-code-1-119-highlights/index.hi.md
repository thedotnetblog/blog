[VS Code 1.119](https://code.visualstudio.com/updates/v1_119) 6 मई 2026 को जारी हुआ (थोड़ी देर बाद 1.119.1 सुरक्षा पैच के साथ)। रिलीज़ एजेंट ऑब्जर्वेबिलिटी, ब्राउज़र इंटरेक्शन और रुकावटें कम करने पर केंद्रित है।

## एजेंट सेशन के लिए OpenTelemetry ट्रेसिंग

यह उन लोगों के लिए प्रमुख फीचर है जो प्रोडक्शन में एजेंट चलाते हैं या एजेंटिक वर्कफ्लो डीबग करते हैं। दो सेटिंग्स से सक्षम करें:

```json
"github.copilot.chat.otel.enabled": true,
"github.copilot.chat.otel.otlpEndpoint": "http://localhost:4318"
```

ट्रेस GenAI सिमेंटिक कन्वेंशन का पालन करती हैं। प्रत्येक एजेंट रिक्वेस्ट एक `invoke_agent` रूट स्पैन उत्पन्न करती है जिसमें नेस्टेड चाइल्ड स्पैन होते हैं: `chat`, `execute_tool` और `execute_hook`। टोकन उपयोग प्रति रिक्वेस्ट रिपोर्ट किया जाता है — कैश रीड और कैश क्रिएशन काउंट सहित।

लोकल एजेंट, Copilot CLI बैकग्राउंड एजेंट और Claude एजेंट के साथ काम करता है। कोई भी OTLP-संगत बैकएंड ट्रेस स्वीकार करता है — [Aspire Dashboard standalone](https://learn.microsoft.com/en-us/dotnet/aspire/fundamentals/dashboard/standalone) लोकल डेवलपमेंट के लिए अच्छा काम करता है।

## एजेंट अब ब्राउज़र टैब एक्सेस कर सकते हैं

एजेंट आपके इंटीग्रेटेड ब्राउज़र टैब तक पहुंच मांग सकते हैं — लेकिन यह स्वचालित नहीं है। आपको कॉन्टेक्स्ट पिकर, ड्रैग-एंड-ड्रॉप, या सुझाए गए कॉन्टेक्स्ट के जरिए एक टैब स्पष्ट रूप से शेयर करना होगा। ब्राउज़र में एक शेयरिंग बटन है जो एक्सेस रद्द करने के लिए है। जब कोई एजेंट उसी डोमेन पर नया टैब खोलने की कोशिश करता है जिस पर एक खुला (अनशेयर) टैब है, VS Code मौजूदा टैब पुनः उपयोग करने के लिए प्रॉम्प्ट करता है।

## ऑप्टिमाइज्ड टोकन उपयोग

एक प्रयोगात्मक हल्का मॉडल अब एजेंट टू-डू लिस्ट मैनेजमेंट संभालता है, इस हाउसकीपिंग को महंगे प्राइमरी मॉडल से दूर रखता है। उन कार्यों पर टोकन बर्न कम करता है जिन्हें पूरी रीजनिंग क्षमता की जरूरत नहीं।

## ट्रस्ट और सुरक्षा

कम रुकावटें: VS Code 1.119 एजेंट्स द्वारा नेटवर्क एक्सेस रिक्वेस्ट और टेम्प फोल्डर राइट के लिए प्रॉम्प्ट कम करता है। 1.119.1 पैच विशिष्ट सुरक्षा मुद्दों को हल करता है — अगर अभी तक नहीं किया तो अपडेट करना उचित है।
