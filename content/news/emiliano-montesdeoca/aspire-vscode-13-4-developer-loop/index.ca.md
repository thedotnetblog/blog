Les millors actualitzacions d'eines són les que notes després d'uns dies, no les que només queden bé a les notes de versió.

Així és com llegeixo **Aspire a VS Code 13.4**.

Aquesta actualització tracta d'ajustar el bucle intern: crear projectes més ràpid, depurar aplicacions de llenguatge mixt de manera més natural, mostrar salut i ordres directament a l'editor, i mantenir el dashboard a prop sense fer-lo l'únic lloc on pots treballar.

Aquesta és una molt bona direcció.

## El gran guany és menys canvi de context

Si utilitzes Aspire seriosament, normalment et mous entre diverses superfícies:

- codi AppHost
- terminal
- dashboard
- logs
- sessions de depuració
- endpoints de servei

El que 13.4 fa bé és reduir la fricció entre aquestes superfícies.

La nova experiència de VS Code fa que més de l'estat de l'aplicació sigui visible exactament on ja estàs treballant:

- salut dels recursos a l'editor
- ordres al costat de les declaracions de recursos
- accés més fàcil al dashboard
- accés als logs des del context d'AppHost
- un panell que segueix sent útil fins i tot abans que comenci la depuració completa

Això sona petit fins que ho fas cada dia.

## Depurar stacks mixtos importa més del que la gent pensa

Una de les parts més sòlides d'aquesta actualització és la història més natural per depurar **C#, TypeScript, Python, Go, aplicacions de navegador i Azure Functions** en un sol flux impulsat per Aspire.

Això reflecteix la forma real de les aplicacions modernes molt millor que pretendre que tot viu en un sol runtime.

Per als desenvolupadors .NET especialment, això és valuós perquè molts de nosaltres ara estem construint sistemes que barregen projectes API, frontends, workers i serveis adjacents a IA en diferents llenguatges.

El fet que Aspire estigui fent que això se senti més unificat dins de VS Code és una millora molt pràctica.

## El suport per a TypeScript AppHost arribant a GA també és significatiu

No ignoraria la banda de TypeScript AppHost d'aquest llançament.

Aspire tornant-se més natural tant per a C# com per a TypeScript amplia qui pot treballar al mateix model de sistema sense fluxos de treball estranys de segona classe. Això importa per a equips on el codi de plataforma, el codi de frontend i l'orquestració de serveis viuen molt a prop.

## La meva opinió

Aspire 13.4 a VS Code no va d'una característica estrella. Va de suavitzar les arestes del bucle diari:

- començar més ràpid
- veure més estat on escrius codi
- depurar de manera més natural
- saltar als logs i al dashboard només quan cal

Així és exactament com hauria d'evolucionar una bona eina.

Si ja utilitzes Aspire, aquesta actualització val la pena instal·lar-la. Si encara et preguntes si VS Code és una llar seriosa per al desenvolupament basat en Aspire, la resposta és cada cop més òbvia.
