Расширение Azure Functions MCP уже давно перешло стадию «смотри, ты можешь выставить инструмент».

Именно это и показывает последнее обновление.

Теперь история стала гораздо шире:

- инструменты
- ресурсы
- промпты
- MCP Apps
- встроенная аутентификация
- лучшие API конфигурации .NET

И это меняет то, как я смотрю на платформу.

## Расширение взрослеет от preview-новинки до настоящего строительного материала

Ранние анонсы MCP в основном касались того, чтобы сам протокол вообще заработал. Полезно, но всё ещё довольно сыро.

Теперь расширение растёт во что-то более полноценное для production-ориентированных команд:

- более богатая поддержка primitives
- лучшая поддержка аутентификации
- структурированный контент и схемы
- более естественная конфигурация .NET через builder
- более понятный путь к интеграции с Foundry

Вот что хочется видеть.

## Почему Azure Functions так хорошо подходит для MCP

Я всё ещё считаю, что Azure Functions — один из самых практичных вариантов хостинга для удалённых MCP-серверов.

Вы получаете:

- serverless-хостинг
- масштабируемое выполнение
- знакомые паттерны triggers и bindings
- встроенную интеграцию с identity
- хорошее соответствие API-подобным tool surface

А с расширением MCP разрыв между «у меня есть полезная функция» и «у меня есть обнаруживаемая агентами tool surface» продолжает сокращаться.

## История fluent builder в .NET особенно хороша

Добавления для .NET привлекли моё внимание, потому что они продолжают тренд к более выразительной конфигурации в коде.

Возможность объявлять метаданные, схемы, UI bindings и более богатое поведение MCP в fluent-стиле делает расширение похожим на инструмент первого класса, а не на тонкую протокольную обёртку.

Именно в этом направлении я и хочу идти.

## Моё мнение

Настоящая история здесь не в одной функции. Дело в том, что расширение Azure Functions MCP становится реалистичным вариантом платформы для команд, которые хотят размещать возможности MCP на Azure, не строя всё с нуля.

И для .NET-разработчиков, в частности, опыт продолжает улучшаться.
