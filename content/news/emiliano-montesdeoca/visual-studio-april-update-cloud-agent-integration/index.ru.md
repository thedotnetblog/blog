[Апрельское обновление Visual Studio 2026 (18.5)](https://devblogs.microsoft.com/visualstudio/visual-studio-april-update-cloud-agent-integration/) включает интеграцию облачного агента, пользовательские агенты на уровне пользователя, инструменты C++, достигающие GA, и новый Агент Отладчика.

## Облачный агент: делегирование работы удалённой сессии Copilot

В средстве выбора агентов в окне Chat выбор **Cloud** позволяет передать задачу удалённому агенту кодирования Copilot. Вы описываете работу, агент создаёт issue на GitHub в вашем репозитории, а затем открывает PR по завершении. Вы получаете уведомление с кнопками "View PR" / "Open in browser" — всё работает пока вы продолжаете кодировать, или даже с закрытой IDE.

## Пользовательские агенты теперь следуют за вами

Пользовательские агенты, хранящиеся в `%USERPROFILE%/.github/agents/`, больше не ограничены одним репозиторием — они следуют за вами между проектами. Путь хранения настраивается в Tools > Параметры > GitHub > Copilot > Chat. Кнопка `+` в средстве выбора агентов позволяет создавать новые агенты напрямую. Они получают те же возможности, что и агенты в области репозитория: осознание рабочей области, инструменты, выбор модели и подключения MCP.

Встроенные агенты: Agent, Ask, Copilot CLI, Debugger, Modernize, Profiler.

## Инструменты редактирования кода C++ становятся GA

Два инструмента — `get_symbol_call_hierarchy` и `get_symbol_class_hierarchy` — теперь включены по умолчанию. Они дают Copilot языковую навигацию по базам кода C++, охватывая иерархии наследования и цепочки вызовов функций. Включите через значок Tools в Copilot Chat. Лучше всего работает с моделями, поддерживающими вызов инструментов.

## Агент Отладчика: исправления проверяются на реальном поведении среды выполнения

Начните с issue GitHub или Azure DevOps (или описания на естественном языке), переключитесь в режим Debugger, и агент:

1. Создаёт минимальный воспроизводитель
2. Генерирует гипотезы сбоя
3. Инструментирует приложение трассировочными точками и условными точками останова
4. Запускает реальную сеанс отладки
5. Анализирует живую телеметрию
6. Предлагает точное исправление

Вы остаётесь в цикле на протяжении всего процесса — это интерактивно, а не полностью автономно.

## Исправление приоритета IntelliSense

VS теперь подавляет завершения Copilot, пока список IntelliSense активен. Только одно предложение за раз. Это была частая точка трения, и теперь включено по умолчанию.
