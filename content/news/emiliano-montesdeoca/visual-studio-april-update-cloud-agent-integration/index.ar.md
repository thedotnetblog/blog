[تحديث Visual Studio 2026 (18.5) لأبريل](https://devblogs.microsoft.com/visualstudio/visual-studio-april-update-cloud-agent-integration/) يشحن تكامل وكيل السحابة، وكلاء مخصصة على مستوى المستخدم، أدوات C++ تصل للإتاحة العامة، ووكيل مصحح جديد.

## وكيل السحابة: تفويض العمل لجلسة Copilot بعيدة

من منتقي الوكيل في نافذة Chat، يتيح لك اختيار **Cloud** تسليم مهمة لوكيل Copilot للترميز عن بُعد. تصف العمل، ينشئ الوكيل مشكلة GitHub في مستودعك، ثم يفتح طلب سحب عند الانتهاء. تحصل على إشعار بـ "View PR" / "Open in browser" — كل شيء يعمل بينما تواصل الترميز، أو حتى مع إغلاق IDE.

## الوكلاء المخصصون تسافر معك الآن

الوكلاء المخصصة على مستوى المستخدم المخزنة في `%USERPROFILE%/.github/agents/` لم تعد مقيدة بمستودع — تتبعك عبر المشاريع. مسار التخزين قابل للتخصيص تحت Tools > Options > GitHub > Copilot > Chat. زر `+` في منتقي الوكيل يتيح لك إنشاء وكلاء جدد مباشرة. تحصل على نفس القدرات: وعي بمساحة العمل، أدوات، اختيار النموذج، واتصالات MCP.

الوكلاء المدمجة: Agent، Ask، Copilot CLI، Debugger، Modernize، Profiler.

## أدوات تحرير كود C++ تصل للإتاحة العامة

أداتان — `get_symbol_call_hierarchy` و`get_symbol_class_hierarchy` — أصبحتا مفعّلتين افتراضياً. تمنحان Copilot التنقل الواعي باللغة في قواعد كود C++، تغطيان تسلسلات الوراثة وسلاسل استدعاء الدوال. فعّل عبر أيقونة Tools في Copilot Chat. يعمل بشكل أفضل مع نماذج استدعاء الأدوات.

## وكيل المصحح: إصلاحات تُتحقق منها مقابل سلوك التشغيل الحقيقي

ابدأ من مشكلة GitHub أو Azure DevOps (أو مجرد وصف بلغة طبيعية)، انتقل إلى وضع Debugger، ويقوم الوكيل بـ:

1. إنشاء حالة استنساخ بسيطة
2. توليد فرضيات الفشل
3. تزويد التطبيق بنقاط تتبع ونقاط توقف مشروطة
4. تشغيل جلسة تصحيح حقيقية
5. تحليل بيانات القياس الحية
6. اقتراح إصلاح دقيق

تبقى في الحلقة طوال العملية — إنه تفاعلي، وليس مستقلاً بالكامل.

## إصلاح أولوية IntelliSense

يُخفي VS الآن اقتراحات Copilot أثناء نشاط قائمة IntelliSense. اقتراح واحد في كل مرة. كان هذا نقطة احتكاك متكررة وأصبح الآن مفعّلاً افتراضياً.
