*I geul-eun jadong beonyeokdoeeossseubnida. wonmun yeongeo boneun [yeogi]({{< ref "index.md" >}}).*

[Visual Studio hwakjang peurojekteu SDK seutail jiwon](https://devblogs.microsoft.com/visualstudio/sdk-style-support-for-extension-projects/)neun .NET siseutemeul unyeonghaneun timiramyeon hwaginhal gachi ga issseubnida.

Jega boneun haeksimeun sae gineung jacheboda ireul eolmana ppalli jaesayong ganeunghan enjinieoring paeteon euro jeonhwanhaneunya imnida.

## .NET tim-e jungyohan iyu

Ireon eobdeiteuneun jeondal sokdo peullaetpom ilgwanseong geobeoneonseu sai ui gyunhyeongeul matchuneun de doumi doebnida.

## Silmu jeogyong dangye

1. Unyeonggwa yusaham deiteoro jageun .NET pailreoseseo meonjeo geomjeunhabnida.
2. hwakjang baepo jeon-e gwancheukseonggwa rollbaeg gijuneul jeong-uihabnida.
3. guhyeon paeteoneul naebu tempeullis-euro munseohwahayeo dareun tim-i jaesayonghage habnida.
