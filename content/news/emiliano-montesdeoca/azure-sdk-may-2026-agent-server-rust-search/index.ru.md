## Часть, на которую я бы обратил внимание

Для меня особенно выделились три вещи:

### 1. Базы знаний Azure AI Search и агентный retrieval

Это, пожалуй, самый интересный с точки зрения стратегии элемент релиза. Новые возможности баз знаний и retrieval усиливают тенденцию к тому, что поисковая инфраструктура становится более aware of agents.

### 2. Новые preview-библиотеки Agent Server

Новые библиотеки хостинга для агентов стоит отслеживать, если вам важны структура runtime, здоровье, поведение при завершении работы и более формальная модель хостинга вокруг endpoints агентов.

### 3. Общее созревание экосистемы

Даже такие вещи, как Rust GA, Batch GA и библиотеки provisioning, важны косвенно, потому что показывают: поверхность Azure SDK продолжает расти по широте и серьезности.
