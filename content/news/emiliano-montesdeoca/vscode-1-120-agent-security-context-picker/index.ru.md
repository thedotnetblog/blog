VS Code 1.120 вышел с набором улучшений агента Copilot, которые небольшие по отдельности, но заметно лучше в повседневном использовании.

## Безопасное Обнаружение Запросов Паролей в Терминалах Агента

Когда агент Copilot выполняет команду терминала, которая вызывает запрос пароля или парольной фразы, VS Code теперь обнаруживает это и показывает диалог подтверждения. Диалог фокусирует терминал, чтобы вы могли напечатать секрет напрямую — и что важно, секреты никогда не маршрутизируются через модель.

Это значительное улучшение безопасности. Ранее агенты, выполняющие команды, которые вызывали подсказки аутентификации, могли создавать ситуации, когда пользователи могли непреднамеренно раскрыть учётные данные. Объявление через экранный диктор означает, что пользователи со специальными возможностями также получают уведомление.

## Выбор Размера Контекста в Выборщике Модели

Новый выборщик размера контекста позволяет выбрать, сколько контекста модель использует для сессии. Разные модели имеют разные размеры окна контекста, и некоторые рабочие процессы выигрывают от его ограничения (меньшая задержка, меньшая стоимость) или максимизации (сложные кодовые базы, длительные сессии).

## Метаданные PR GitHub в Сессиях Agent Host

Для сессий, поддерживаемых репозиторием GitHub, VS Code теперь показывает метаданные GitHub — включая кнопку pull request — в пользовательском интерфейсе agent host. Меньше переключения контекста в браузер или расширение GitHub, когда вы работаете над PR.

## Управление Архивом Сессий Чата

Два улучшения для Quick Pick сессий:
- Архивированные сессии скрыты по умолчанию (меньше визуального беспорядка)
- Поиск всё ещё соответствует архивированным сессиям, поэтому вы можете восстановить одну по названию

Сессии также по умолчанию группируются по давности, что облегчает поиск недавней работы.

## Обнаружение Плагинов CLI Copilot

VS Code теперь автоматически обнаруживает установленные пользователем плагины Copilot CLI из `~/.copilot/installed-plugins/`. Если вы настроили WinUI или другие специфические для домена навыки агента, они подхватываются без ручной настройки.

## API Пользовательского Редактора Diff (Предварительный Просмотр)

Для авторов расширений: новый предложенный API `customDiffEditorProvider` позволяет расширениям отображать унифицированный diff в одном webview с доступом к оригинальным и изменённым документам, вместо двух расположенных рядом пользовательских представлений редактора.

Оригинальная публикация: [Visual Studio Code 1.120](https://code.visualstudio.com/updates/v1_120)
