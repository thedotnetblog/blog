شُحن VS Code 1.120 مع مجموعة من التحسينات على وكيل Copilot، صغيرة بشكل فردي لكن أفضل بشكل ملحوظ في الاستخدام اليومي.

## اكتشاف آمن لمطالبات كلمة المرور في طرفيات الوكيل

عندما ينفذ وكيل Copilot أمر طرفية يُشغّل مطالبة بكلمة مرور أو عبارة مرور، يكتشف VS Code الآن هذا ويعرض مربع حوار للتأكيد. يركّز مربع الحوار الطرفية حتى تتمكن من كتابة السر مباشرة — والأهم، لا يتم توجيه الأسرار عبر النموذج أبدًا.

هذا تحسين أمني مهم. في السابق، كانت الوكلاء الذين ينفذون أوامر تُشغّل مطالبات المصادقة قد تخلق مواقف قد يكشف فيها المستخدمون عن بيانات اعتماد بشكل غير مقصود. إعلان قارئ الشاشة يعني أن مستخدمي إمكانية الوصول يتلقون الإشعار أيضًا.

## منتقي حجم السياق في منتقي النموذج

يتيح لك منتقي حجم السياق الجديد تحديد مقدار السياق الذي يستخدمه النموذج لجلسة. تمتلك النماذج المختلفة أحجامًا مختلفة لنافذة السياق، وتستفيد بعض مسارات العمل من تقييدها (زمن استجابة أقل، تكلفة أقل) أو تعظيمها (قواعد بيانات معقدة، جلسات طويلة الأمد).

## بيانات PR التعريفية من GitHub في جلسات Agent Host

بالنسبة للجلسات المدعومة بمستودع GitHub، يعرض VS Code الآن بيانات GitHub التعريفية — بما في ذلك زر طلب السحب — في واجهة مستخدم host الوكيل. تبديل سياق أقل إلى المتصفح أو امتداد GitHub عند العمل على PR.

## إدارة أرشيف جلسات الدردشة

تحسينان لـ Quick Pick للجلسات:
- الجلسات المؤرشفة مخفية بشكل افتراضي (فوضى بصرية أقل)
- البحث لا يزال يطابق الجلسات المؤرشفة، حتى تتمكن من إحياء واحدة بالعنوان

يتم أيضًا تجميع الجلسات حسب الحداثة بشكل افتراضي، مما يُسهّل العثور على العمل الأخير.

## اكتشاف مكوّنات CLI الإضافية لـ Copilot

يكتشف VS Code الآن تلقائيًا مكوّنات CLI لـ Copilot المثبتة من قِبل المستخدم من `~/.copilot/installed-plugins/`. إذا كنت قد أعددت WinUI أو مهارات وكيل محددة بنطاق معين، يتم التعرف عليها بدون تهيئة يدوية.

## واجهة برمجة تطبيقات محرر الفرق المخصص (معاينة)

لمؤلفي الامتدادات: تتيح واجهة برمجة التطبيقات المقترحة الجديدة `customDiffEditorProvider` للامتدادات عرض فرق موحد في webview واحدة مع الوصول إلى المستندات الأصلية والمعدلة، بدلاً من طريقتَي عرض محرر مخصص جنبًا إلى جنب.
