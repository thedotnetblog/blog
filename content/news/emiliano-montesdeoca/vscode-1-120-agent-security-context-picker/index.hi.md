VS Code 1.120 Copilot एजेंट सुधारों के एक सेट के साथ शिप हुआ जो व्यक्तिगत रूप से छोटे हैं लेकिन दिन-प्रतिदिन के उपयोग में काफी बेहतर हैं।

## एजेंट टर्मिनल में सुरक्षित पासवर्ड प्रॉम्प्ट डिटेक्शन

जब एक Copilot एजेंट एक टर्मिनल कमांड चलाता है जो पासवर्ड या पासफ्रेज प्रॉम्प्ट ट्रिगर करता है, VS Code अब इसे डिटेक्ट करता है और एक पुष्टि संवाद दिखाता है। संवाद टर्मिनल पर फोकस करता है ताकि आप सीधे रहस्य टाइप कर सकें — और महत्वपूर्ण रूप से, रहस्य कभी भी मॉडल के माध्यम से रूट नहीं होते।

यह एक महत्वपूर्ण सुरक्षा सुधार है। पहले, एजेंट जो कमांड चला रहे थे जो प्रमाणीकरण प्रॉम्प्ट ट्रिगर करते थे, ऐसी स्थिति बना सकते थे जहां उपयोगकर्ता अनजाने में क्रेडेंशियल उजागर कर सकते थे। स्क्रीन रीडर घोषणा का मतलब है कि एक्सेसिबिलिटी उपयोगकर्ताओं को भी अधिसूचना मिलती है।

## मॉडल पिकर में संदर्भ आकार चयनकर्ता

एक नया संदर्भ आकार चयनकर्ता आपको यह चुनने देता है कि मॉडल एक सत्र के लिए कितना संदर्भ उपयोग करता है। विभिन्न मॉडलों में अलग-अलग संदर्भ विंडो आकार होते हैं, और कुछ वर्कफ्लो इसे प्रतिबंधित करने (कम विलंबता, कम लागत) या अधिकतम करने (जटिल कोडबेस, लंबे समय तक चलने वाले सत्र) से लाभान्वित होते हैं।

## Agent Host सत्रों में GitHub PR मेटाडेटा

GitHub रिपॉजिटरी द्वारा समर्थित सत्रों के लिए, VS Code अब agent host UI में GitHub मेटाडेटा — एक पुल रिक्वेस्ट बटन सहित — प्रदर्शित करता है। PR पर काम करते समय ब्राउज़र या GitHub एक्सटेंशन पर कम संदर्भ स्विचिंग।

## चैट सत्र संग्रह प्रबंधन

सत्रों Quick Pick के लिए दो सुधार:
- संग्रहीत सत्र डिफ़ॉल्ट रूप से छिपे हुए हैं (कम दृश्य अव्यवस्था)
- खोज अभी भी संग्रहीत सत्रों से मेल खाती है, इसलिए आप शीर्षक से एक को पुनर्जीवित कर सकते हैं

सत्र डिफ़ॉल्ट रूप से हालिया क्रम में भी समूहित होते हैं, जिससे हाल के काम को ढूंढना आसान हो जाता है।

## Copilot CLI प्लगइन डिस्कवरी

VS Code अब `~/.copilot/installed-plugins/` से इंस्टॉल किए गए Copilot CLI उपयोगकर्ता प्लगइन को स्वचालित रूप से डिस्कवर करता है। यदि आपने WinUI या अन्य डोमेन-विशिष्ट एजेंट स्किल सेट किए हैं, तो उन्हें बिना मैन्युअल कॉन्फ़िगरेशन के पिक अप किया जाता है।

## कस्टम Diff एडिटर API (पूर्वावलोकन)

एक्सटेंशन लेखकों के लिए: एक नया प्रस्तावित API `customDiffEditorProvider` एक्सटेंशन को दो साइड-बाय-साइड कस्टम एडिटर व्यू के बजाय मूल और संशोधित दोनों दस्तावेजों तक पहुंच के साथ एकल webview में एकीकृत diff रेंडर करने देता है।
