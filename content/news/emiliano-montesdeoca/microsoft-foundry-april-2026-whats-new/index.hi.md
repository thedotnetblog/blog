Microsoft Foundry के लिए एक व्यस्त महीना था। यहाँ सबसे महत्वपूर्ण घोषणाएं हैं।

## Foundry Local सामान्य रूप से उपलब्ध

Foundry Local — Microsoft का क्रॉस-प्लेटफ़ॉर्म लोकल AI रनटाइम — Windows, macOS (Apple Silicon) और Linux x64 पर प्रीव्यू से GA में चला गया है। डेवलपर-फ्रेंडली SDK के साथ प्रोडक्शन-रेडी लोकल मॉडल इनफरेंस। संस्करण 1.1 ट्रांसक्रिप्शन, embeddings और Responses API सहायता जोड़ता है।

## GPT-5.5

GPT-5 परिवार का नवीनतम मॉडल अब Foundry में उपलब्ध है। Tier 5 और Tier 6 सदस्यताओं के लिए डिफ़ॉल्ट कोटा। यदि आप पहले के GPT-5 वैरिएंट के साथ काम कर रहे थे, तो अपने उपयोग मामले के खिलाफ मूल्यांकन करना उचित है।

## Foundry में Agent Framework ट्रेसिंग

इस महीने दो ट्रेसिंग सुविधाएं प्रीव्यू में आती हैं:

**Microsoft Agent Framework ट्रेसिंग** — MAF एजेंट अब Foundry को OpenTelemetry ट्रेस भेज सकते हैं। एजेंट व्यवहार को डीबग करें, मल्टी-स्टेप निष्पादन को ट्रेस करें, टूल कॉल में लेटेंसी और एरर दिखाएं। यह एक वास्तविक अंतराल को भरता है: यह जानना कि *एजेंट ने प्रोडक्शन में वास्तव में क्या किया*, न केवल यह कि उसने क्या लौटाया।

**होस्टेड एजेंट ट्रेसिंग** — होस्टेड एजेंट के सेशन, टूल कॉल और रन स्टेप भी Foundry ट्रेस में दिखते हैं। वही ऑब्जर्वेबिलिटी कहानी होस्टेड टियर तक फैलती है।

## Hyperlight के साथ CodeAct (Alpha)

यह तकनीकी रूप से सबसे दिलचस्प जोड़ है: Agent Framework अब [Hyperlight](https://github.com/hyperlight-dev/hyperlight) माइक्रो वर्चुअल मशीनों के अंदर Python कोड निष्पादित कर सकता है।

CodeAct वह पैटर्न है जहाँ एजेंट टूल के रूप में Python कोड जेनरेट और निष्पादित करते हैं। स्पष्ट चिंता सुरक्षा है — आप मॉडल-जेनरेटेड कोड चला रहे हैं। Hyperlight के माइक्रो VM नेटिव-नियर स्टार्टअप टाइम के साथ प्रोसेस-लेवल आइसोलेशन प्रदान करते हैं, जिससे फुल कंटेनर या VM के ओवरहेड के बिना सैंडबॉक्स कोड एक्जीक्यूशन व्यावहारिक बनता है।

कोड एक्जीक्यूशन की जरूरत वाले एजेंट वर्कफ्लो के लिए, यह होस्ट प्रोसेस में कोड चलाने की तुलना में महत्वपूर्ण सुरक्षा सुधार है।

## Agent Monitoring Dashboard (प्रीव्यू)

एक यूनिफाइड ऑपरेशनल डैशबोर्ड जो टोकन उपयोग, लेटेंसी, रन सक्सेस रेट और इवैल्यूएटर स्कोर को एक व्यू में जोड़ता है। नियमित ऑब्जर्वेबिलिटी डैशबोर्ड से अंतर: इसमें ऑपरेशनल मेट्रिक्स के साथ-साथ इवैल्यूएशन परिणाम शामिल हैं, इसलिए आप "एजेंट धीमा हो गया" को "इवैल्यूएटर स्कोर गिर गए" से जोड़ सकते हैं — या पुष्टि कर सकते हैं कि वे असंबंधित हैं।

## निरंतर मूल्यांकन कस्टम इवैल्यूएटर (प्रीव्यू)

अब आप अपने खुद के कोड-आधारित या प्रॉम्प्ट-आधारित इवैल्यूएटर निरंतर मूल्यांकन पाइपलाइन में ला सकते हैं। पहले, निरंतर मूल्यांकन बिल्ट-इन इवैल्यूएटर तक सीमित था। कस्टम इवैल्यूएटर आपको प्रोडक्शन मॉनिटरिंग लूप में टीम-विशिष्ट गुणवत्ता मानक लागू करने देते हैं।

## कंट्रोल प्लेन में एजेंट इन्वेंट्री

Foundry कंट्रोल प्लेन Operate व्यू अब आपके सदस्यता में सभी समर्थित एजेंट दिखाता है: Foundry एजेंट, Azure SRE Agent, Logic Apps एजेंट लूप और रजिस्टर्ड कस्टम एजेंट। क्या कहाँ डिप्लॉय है, यह समझने के लिए एक व्यू।
