Visual Studio 2026 अप्रैल अपडेट: क्लाउड एजेंट, कस्टम एजेंट और डीबगर एजेंट

Visual Studio 2026 (18.5) के अप्रैल अपडेट में क्लाउड एजेंट इंटीग्रेशन, यूज़र-लेवल कस्टम एजेंट, C++ टूल्स GA, और एक डीबगर एजेंट आया है जो असली रनटाइम व्यवहार के खिलाफ फिक्स को वैलिडेट करता है।

Visual Studio 2026 (18.5) अप्रैल अपडेट में क्लाउड एजेंट इंटीग्रेशन, यूज़र-लेवल कस्टम एजेंट, C++ टूल्स GA होते हैं, और एक नया डीबगर एजेंट शामिल है।

क्लाउड एजेंट: रिमोट Copilot सेशन को काम सौंपें

Chat विंडो के एजेंट पिकर से Cloud चुनने से आप एक रिमोट Copilot कोडिंग एजेंट को काम सौंप सकते हैं। काम बताएं, एजेंट आपके रेपो में GitHub issue बनाता है, फिर पूरा होने पर PR खोलता है। आपको “View PR” / “Open in browser” के साथ नोटिफिकेशन मिलता है — सब कुछ तब भी चलता है जब आप कोडिंग जारी रखते हैं, या IDE बंद होने पर भी।

कस्टम एजेंट अब आपके साथ चलते हैं

%USERPROFILE%/.github/agents/ में संग्रहीत यूज़र-लेवल कस्टम एजेंट अब रेपो तक सीमित नहीं हैं — वे प्रोजेक्ट्स के पार आपके साथ चलते हैं। स्टोरेज पाथ Tools > Options > GitHub > Copilot > Chat में कॉन्फ़िगर किया जा सकता है। एजेंट पिकर में + बटन से सीधे नए एजेंट बनाए जा सकते हैं। उन्हें रेपो-स्कोप्ड एजेंट जैसी ही क्षमताएं मिलती हैं: वर्कस्पेस अवेयरनेस, टूल्स, मॉडल सिलेक्शन और MCP कनेक्शन।

बिल्ट-इन एजेंट: Agent, Ask, Copilot CLI, Debugger, Modernize, Profiler।

C++ कोड एडिटिंग टूल्स GA हो गए

दो टूल्स — get_symbol_call_hierarchy और get_symbol_class_hierarchy — अब डिफ़ॉल्ट रूप से चालू हैं। ये Copilot को C++ कोडबेस में भाषा-जागरूक नेविगेशन देते हैं, इनहेरिटेंस हाइरार्की और फंक्शन कॉल चेन को कवर करते हैं। Copilot Chat में Tools आइकन से सक्षम करें। टूल-कॉलिंग मॉडल के साथ सबसे अच्छा काम करता है।

डीबगर एजेंट: असली रनटाइम व्यवहार के खिलाफ फिक्स वैलिडेट

GitHub या Azure DevOps issue (या प्राकृतिक भाषा विवरण) से शुरू करें, Debugger मोड में जाएं, और एजेंट:

  1. न्यूनतम रिप्रोड्यूसर बनाता है
  2. फेलियर हाइपोथेसिस जनरेट करता है
  3. ट्रेसपॉइंट्स और कंडीशनल ब्रेकपॉइंट्स के साथ ऐप इंस्ट्रूमेंट करता है
  4. असली डीबग सेशन चलाता है
  5. लाइव टेलीमेट्री एनालाइज़ करता है
  6. सटीक फिक्स सुझाता है

पूरी प्रक्रिया में आप लूप में रहते हैं — यह इंटरेक्टिव है, पूरी तरह स्वायत्त नहीं।

IntelliSense प्राथमिकता फिक्स

IntelliSense सूची एक्टिव होने पर VS अब Copilot completions दबा देता है। एक समय में एक ही सुझाव। यह एक बार-बार होने वाला फ्रिक्शन पॉइंट था और अब यह डिफ़ॉल्ट रूप से चालू है।

पूर्ण रिलीज़ नोट्स और डाउनलोड devblogs.microsoft.com पर।
