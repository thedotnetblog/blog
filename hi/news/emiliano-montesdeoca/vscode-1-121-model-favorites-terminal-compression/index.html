VS Code 1.121: पसंदीदा मॉडल पिन करें, टर्मिनल आउटपुट कम्प्रेशन, एजेंट SSH

VS Code 1.121 मॉडल पसंदीदा, टेस्ट रनर और बिल्ड टूल के लिए विस्तारित टर्मिनल आउटपुट कम्प्रेशन, बैकग्राउंड टर्मिनल के लिए आइडल-साइलेंस टाइमर और agent host में कीबोर्ड-इंटरेक्टिव SSH प्रमाणीकरण जोड़ता है।

VS Code 1.121 1.120 से Copilot एजेंट गुणवत्ता सुधारों को जारी रखता है, मॉडल प्रबंधन और टर्मिनल व्यवहार पर ध्यान केंद्रित करते हुए।

पसंदीदा मॉडल पिन करें

मॉडल पिकर अब पिनिंग का समर्थन करता है। यदि आप हमेशा एक ही मॉडल या दो तक पहुंचते हैं, तो उन्हें सूची के शीर्ष पर पिन करें। कई प्रदाताओं से कई मॉडल तक पहुंच होने पर स्क्रॉलिंग कम हो जाती है।

विस्तारित टर्मिनल आउटपुट कम्प्रेशन

एजेंट टर्मिनल टूल पहले से ही सामान्य कमांड के लिए आउटपुट को संपीड़ित करता था। 1.121 इसे टेस्ट रनर और बिल्ड टूल को कवर करने के लिए विस्तारित करता है:

  • टेस्ट रनर: pytest, jest, cargo test
  • बिल्ड टूल: tsc, cargo build, make
  • लिंटर, Docker, पैकेज मैनेजर

लंबे बिल्ड आउटपुट और टेस्ट विफलता रिपोर्ट मॉडल को पास होने से पहले प्रासंगिक अंशों में संपीड़ित की जाती हैं। यह संदर्भ उपयोग को प्रबंधनीय रखता है जब एजेंट बिल्ड साइकल या टेस्ट सूट चलाता है, जो हजारों आउटपुट लाइनें उत्पन्न कर सकते हैं।

बैकग्राउंड टर्मिनल के लिए आइडल-साइलेंस टाइमर

run_in_terminal टूल के लिए एक नया आइडल-साइलेंस टाइमर: यदि एक सिंक कमांड कॉन्फिगर करने योग्य अवधि के लिए कोई आउटपुट नहीं उत्पन्न करता है, तो यह स्वचालित रूप से बैकग्राउंड निष्पादन में प्रमोट हो जाता है। यह लंबे समय तक चलने वाले कमांड को एजेंट को ब्लॉक करने से रोकता है जब वे चुपचाप प्रोसेस कर रहे होते हैं। आपको बाद में जांचने के लिए एक टर्मिनल ID मिलता है।

VSCODE_AGENT पर्यावरण चर

जब Copilot Chat टर्मिनल में कमांड चलाता है, तो एक VSCODE_AGENT पर्यावरण चर अब सेट किया जाता है। उपयोगी है यदि आपके पास स्क्रिप्ट या टूल हैं जो एजेंट सेशन से बुलाए जाने पर बनाम इंटरेक्टिव रूप से अलग तरह से व्यवहार करते हैं।

ब्राउज़र से चैट में जोड़ें

एकीकृत ब्राउज़र में राइट-क्लिक अब “चैट में जोड़ें” विकल्प दिखाता है। एक वेब पेज से कंटेंट चुनें और कॉपी-पेस्ट किए बिना इसे सीधे अपने Copilot Chat संदर्भ में जोड़ें।

ठीक किया: Agent Host में मल्टी-लाइन शेल कमांड

एक प्रतीक्षित बग फिक्स: Agent Host टर्मिनल टूल में मल्टी-लाइन शेल कमांड अब सही ढंग से काम करते हैं। पहले ये विफल हो सकते थे या गलत व्यवहार उत्पन्न कर सकते थे।

कीबोर्ड-इंटरेक्टिव SSH प्रमाणीकरण

Agent Host SSH कनेक्शन अब कीबोर्ड-इंटरेक्टिव प्रमाणीकरण का समर्थन करते हैं — कुछ SSH सर्वर (कुछ पुरानी कॉर्पोरेट कॉन्फिगरेशन सहित) द्वारा उपयोग की जाने वाली फॉलबैक प्रमाणीकरण विधि। रिमोट SSH होस्ट पर काम करने वाले एजेंट को ऑथ विफलताओं का सामना करने की संभावना कम है।
